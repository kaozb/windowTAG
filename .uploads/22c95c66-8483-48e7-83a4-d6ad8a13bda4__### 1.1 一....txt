
### 1.1 一句话定位

**面向 Windows 的本地快捷启动面板**：把常用文件、文件夹、网址、UWP 应用和系统功能，按“分组 → 标签 → 链接”组织成一块可贴边隐藏的快捷面板，用鼠标或全局热键随时唤起。

### 1.2 设计原则

| 原则 | 具体表现 | 对自研的约束 |
|---|---|---|
| 极简 | 主界面只有分组、标签、链接与少量按钮；官方明确“不添加绚丽特效或复杂冗余功能”[1] | 拒绝仪表盘化、拒绝多级设置迷宫 |
| 快速 | 单 EXE、冷启动直接进入面板；全局热键/鼠标滑入即可显现 | 启动路径不得依赖网络、安装器、后台服务 |
| 绿色便携 | 配置与数据库均在程序目录；不写注册表、不联网[1] | 所有状态用文件保存，路径一律相对 EXE |
| 键盘优先 | 全局热键、输入即搜索、方向键选择、Shift+方向键移动 | 核心操作必须有键盘等价路径 |
| 低打扰 | 贴边自动隐藏、失焦隐藏、托盘常驻、可钉住 | 显隐状态必须可预测、可关闭 |
| 数据自持 | SQLite 本地库 + 图标缓存库，用户可备份迁移 | 数据模型要可导出、可迁移、可修复 |

### 1.3 目标用户与场景

- 桌面图标长期堆满、希望“一块面板管所有入口”的重度电脑用户。
- 需要频繁在固定几组工具/文档/项目目录之间切换的办公、开发、运维人员。
- 偏好免安装、离线、无账号体系工具的用户。

典型场景：

1. 鼠标移到屏幕边缘，面板滑出，点击“开发”分组下的“终端”标签启动。
2. 从资源管理器把文件夹直接拖进面板，自动生成链接。
3. 按全局热键唤起搜索框，输入多个关键字定位文件并打开。
4. 在“便签”标签里记录临时文本，切换标签自动保存。

### 1.4 功能地图

| 优先级 | 模块 | 能力 |
|---|---|---|
| P0 | 分组 / 标签 / 链接 | 三级组织、增删改、拖拽排序、跨组移动 |
| P0 | 启动器 | 文件、文件夹、URL、Shell 命令、虚拟目录、管理员启动 |
| P0 | 显隐与唤起 | 贴边隐藏、四角隐藏、全局热键、鼠标中键、双击桌面/任务栏 |

## 2. 信息架构与界面设计

### 2.1 三级信息模型 ✅

```text
分组（Group，一级容器，可嵌套）
└── 标签（Tag，二级容器，挂在分组下）
    └── 链接（Link，可启动项）
```

数据库只有 `Groups` 与 `Links` 两张业务表，说明**分组与标签共用一张自引用表**：

- `Groups.ParentGroup = 0` 表示一级分组；
- `Groups.ParentGroup = 分组ID` 表示该分组下的标签；
- `Groups.TYPE` 区分节点类型（普通分组 / 标签 / 特殊节点）；
- `Links.ParentGroup` 指向所属标签（或分组）；
- `Groups.SORT` 与 `Groups.POS` 分别承担“排序模式”和“手动位置”；
- `Groups.Content` 承载便签文本。

> 这是整个产品最值得复用的数据结构：**用一棵自引用树同时表达分组、标签和特殊页**，避免为“标签”再建一张几乎相同的表。

### 2.2 特殊页与特殊标签

- ✅ 固定特殊页：**“全部”**（聚合当前分组的所有链接）、**“便签”**（记录文字信息）。
- ✅ 内部使用 `#` 前缀标记内置项与行为，例如 `#dir`、`#url`、`#uwp`、`#Sys`、`#Shutdown`、`#VolumeUp`。完整列表见附录 A。
- ◐ 这些标记更像“伪协议/伪路径”：存入 `Links.PATH` 或 `Links.TYPE`，由启动器分发到对应处理分支。

设计建议（○）：自研时把它定义为显式的 `LinkKind` 枚举 + `payload` 字段，不要把行为编码进路径字符串，否则后续扩展和迁移会很痛苦。

### 2.3 主界面区域

样本中可确认的控件命名（DUI XML 控件 ID）✅：

`btn_close`、`btn_menu`、`btn_search`、`btn_skin`、`titlebox`、`date`、`major_group_box`、`minor_group_line`、`list_major_group`、`list_minor_group`、`linktabbox`、`edit_todo`、`tag_lnk_box`、`listitem_majorgroup`、`listitem_minorgroup`、`menu_*` 系列。

据此还原的界面结构：

```text
┌────────────────────────────────────────────────────────────┐
│ 标题栏   [搜索] [菜单] [皮肤] [关闭]                日期   │  titlebox / date
├──────────────┬─────────────────────────────────────────────┤
│ 分组栏       │ 标签栏： 全部 │ 便签 │ 标签A │ 标签B │ ...  │  major_group_box
│ ┌──────────┐ │                                             │  minor_group_line
│ │ 分组 1   │ ├─────────────────────────────────────────────┤
│ │ 分组 2   │ │                                             │
│ │ 分组 3   │ │   链接区（图标 + 名称，网格/列表）          │  linktabbox
│ │ ...      │ │   [图标] 名称   [图标] 名称   [图标] 名称   │
│ └──────────┘ │                                             │
│              │                                             │
│              │   便签编辑区（仅“便签”页）                  │  edit_todo
└──────────────┴─────────────────────────────────────────────┘
```

布局规则（○ 建议）：

- 分组栏宽度可通过 `nGroupWidth` 固定，或 `bAutoGroupWidth` 自适应；支持左右换边（`bGroupRight`）。
- 标签栏支持左右换边（`bTagRight`）、对齐方式（`TagAlign`）、高度固定或自适应（`nTagWidth` / `bAutoTagHeight`）。
- 标题栏、分组栏、标签栏均可整体隐藏（`bShowTitle` / `bShowGroup` / `bShowTag`），用于“只留链接区”的极简形态。
- 链接名支持单行省略（`bLnkNameSingleline`），避免长文件名撑破网格。
- 透明度 `nAlpha` 作用于整体窗口，适合贴在桌面侧边时不遮挡内容。

### 2.4 界面状态模型

| 状态 | 触发 | 表现 |
|---|---|---|
| 显示 | 热键 / 鼠标滑入热区 / 托盘 / 双击桌面 | 面板滑出或淡入，获得焦点 |
| 隐藏 | 失焦 / 鼠标离开延时 / 启动链接后 / 启动程序时 | 收到边缘或完全隐藏 |
| 钉住 | 主菜单“钉住” | 暂停自动隐藏，便于拖拽添加 |
| 搜索 | 热键 / 输入字符 | 搜索框与结果层覆盖链接区 |
| 拖拽 | 从外部拖入 / 内部拖动 | 高亮插入位，松开落库 |
| 编辑 | 右键编辑 / 新建 | 弹出命名、URL、图标、备注等窗口 |

> 样本中 `LucyTopWnd` 与 `LucyWnd` 分离，说明“贴边触发”由一个独立的边缘窗口负责，而不是主窗口自己监听鼠标。这是贴边类工具的标准做法（更新记录也提到 WorkerW 窗口引发的显隐问题[1]）。

### 3.3 拖拽添加：输入解析设计

这是产品的核心“低摩擦”入口，建议按以下决策树实现（○，与样本行为一致）：

```text
拖入数据
├── CF_HDROP（文件列表）
│   ├── .lnk            → 解析目标、参数、工作目录、图标
│   ├── .url            → 读取 URL，尝试 icons/url/<域名>.ico|png|svg
│   ├── 文件夹          → 目录链接，图标取文件夹图标或自定义
│   ├── .exe/.dll       → 可执行链接，支持选择图标与图标索引
│   └── 普通文件        → 文件链接，Shell 打开
├── 浏览器拖入的 URL     → 网址链接，按域名加载图标
├── Shell 虚拟项（Pidl） → 我的电脑/控制面板/回收站等，保存 Pidl BLOB
└── UWP 应用（Appx）     → 保存 AUMID，启动时走 shell:AppsFolder
```

要点：

- ✅ 链接表保留 `PATH`、`Parameter`、`WorkDir`、`ShowCmd`、`IsAdmin`、`Pidl`，足以表达 Shell 启动语义。
- ✅ 支持从 EXE/DLL 资源中选择图标并指定索引（v1.7.9）。
- ✅ 支持 WebP 图标（v1.7.9）。
- ○ 拖拽落点应决定归属：落在标签上即加入该标签，落在分组上加入默认标签。

### 3.4 贴边显隐状态机

```mermaid
stateDiagram-v2
    state "显示" as Shown
    state "收起" as Collapsed
    state "钉住" as Pinned
    state "隐藏" as Hidden

    [*] --> Shown
    Shown --> Collapsed: 失焦 / 鼠标离开延时 / 启动链接后
    Collapsed --> Shown: 鼠标进入热区 / 热键 / 托盘
    Shown --> Pinned: 菜单钉住
    Pinned --> Shown: 取消钉住
    Collapsed --> Hidden: 启动时隐藏 / 全屏模式
    Hidden --> Shown: 热键 / 托盘 / 双击桌面
```

设计约束（○）：

1. **热区独立**：边缘热区窗口只负责判定“鼠标是否进入”，不参与主窗口焦点，避免抢焦点。
2. **延时防抖**：进入与离开都加延时（`nDockDelay`、激活延时），避免鼠标划过时闪烁。
3. **多显示器**：以鼠标所在显示器的工作区为贴边基准，任务栏位置变化时重新计算。
4. **全屏抑制**：检测前台全屏应用时暂停自动弹出（`bFullScreenMode`）。
5. **钉住优先**：钉住状态下忽略所有自动隐藏条件。
6. **显隐互斥**：贴边隐藏、启动时隐藏、失焦隐藏三者必须有统一状态机，否则会出现“互相打架”（官方在 v1.7.4、v1.7.5 连续修复此类问题[1]）。

### 3.5 菜单结构

主菜单（`btn_menu`）建议包含：

- 添加分组 / 添加标签 / 添加链接
- 排序方式（手动 / 启动次数 / 首字母，v1.8.6 增加统一排序入口）
- 钉住（v1.8.6）
- 系统功能（v1.8.1 起内置，无需先添加链接）
- 设置、皮肤、帮助、常见问题、赞赏、关于、退出

右键链接菜单：打开、打开所在位置、以管理员身份运行、编辑、设置图标、复制路径、删除（可按 `bDelConfirm` 二次确认）。

### 3.6 设置页

设置项按“外观 / 行为 / 热键 / 搜索 / 数据 / 关于”分组，避免单页平铺。样本的配置键已经覆盖了较完整的产品面（见第 7 章），可直接作为设置页字段清单。

### 3.7 反馈与错误

样本内置的错误文案 ✅：

- `链接数据库加载失败!`
- `图标缓存加载失败!`
- `系统功能初始化失败!`
- `注册快捷键 %s 失败!`
- `主题[%s]加载失败！将使用默认主题！`
- `64位系统下建议使用x64版本！`

设计原则（○）：**单项失败降级，不阻断启动**。数据库失败进入只读/空库模式，图标失败回退实时提取，主题失败回退默认主题，热键失败提示但不退出。

## 4. 视觉、主题与资源设计

### 4.1 视觉基调

- ✅ 界面由 NIM_Duilib 自绘（字符串可见 `WindowImplBase`、`CTxtWinHost`、`ui::Window`），不是原生控件拼装，因此可以实现无边框、圆角、半透明、自定义标题栏。
- 主色取自应用图标：**蓝色系**（图标为蓝色圆角“L”），辅以中性灰背景。
- 信息层级依靠“图标 + 名称”的网格重复建立节奏，装饰元素应极少。

### 4.2 图标体系

| 类型 | 来源 | 规格 |
|---|---|---|
| 应用图标 | `RT_GROUP_ICON 128`，含 16/20/24/32/40/48/64 等多尺寸 | 托盘与窗口图标 |
| 分组图标 | `RT_GROUP_ICON 203–207`、`210` | 分组/标签标识 |
| 系统功能图标 | 资源 208、209、211–215（SVG） | 电源、重启、静音、音量、锁定、睡眠 |
| 链接图标 | Shell 提取 / EXE-DLL 资源 / 自定义图片 / URL 域名 | 16/32/48 三档 |
| 缓存 | `db/icon.db` 的 `Cache` 表 | 每链接三档 BLOB |

- ✅ `Cache` 表字段为 `ID / Invalid / Icon16 / Icon32 / Icon48`，说明缓存是**按链接记录、按尺寸分档**的 BLOB 存储。
- ✅ URL 图标目录约定为 `icons/url/<域名>.ico|.png|.svg`。
- ○ 建议：图标提取放到工作线程，主线程只读缓存；`Invalid` 标记用于路径变更或主题切换后的惰性刷新。

### 4.3 主题 token 设计

样本主题位于 `theme/*.xml` 与 `skin/`，皮肤资源类型为自定义 `RT_SKIN = 1912`。加密皮肤包内含 `skin/gray/global.xml`、`main/*.xml`、`menu/*.xml`、`public/*.png` 等 97 个文件、10 个目录 ✅（包已加密，未能读取 XML 细则）。

自研建议采用“**XML 布局 + 颜色/尺寸变量 + 图片资源**”的结构：

```xml
<!-- theme/default/global.xml（示例，非样本原文） -->
<theme name="default" version="1">
  <colors>
    <color id="bg"          value="#F6F8FA"/>
    <color id="panel"       value="#FFFFFF"/>
    <color id="text"        value="#0F1B26"/>
    <color id="textMuted"   value="#5A6B7B"/>
    <color id="accent"      value="#1178B4"/>
    <color id="hover"       value="#E8F1F8"/>
    <color id="split"       value="#D8E2EA"/>
  </colors>
  <metrics>
    <metric id="titleHeight" value="40"/>
    <metric id="groupWidth"  value="168"/>
    <metric id="tagHeight"   value="36"/>
    <metric id="iconSize"    value="32"/>
    <metric id="itemGap"     value="10"/>
  </metrics>
  <images>
    <image id="close"  value="public/close.svg"/>
    <image id="search" value="public/search.svg"/>
  </images>
</theme>
```

设计规则：

1. **颜色不写死在代码里**，全部通过 token 取。
2. **SVG 优先**，位图仅用于照片类背景。
3. **主题包自带 fallback**：任一 token 缺失使用默认值。
4. **加载顺序**：用户主题 → `skin/` 外部皮肤 → 内置默认主题；任一步失败都继续降级。
5. ○ 自研不必沿用加密 ZIP：可直接用普通 ZIP + `manifest.json` + 校验和，便于审计与用户自制主题。若确实要保护资源，再考虑加密，但需明确密码管理方案。

### 4.4 字体、DPI 与透明度

- 中文界面，默认字体跟随系统 UI 字体；数字/日期可用等宽字体增强对齐感。
- 必须声明 **Per-Monitor V2 DPI 感知**，否则在 125%/150% 缩放下贴边坐标与图标会错位。
- `nAlpha` 建议范围 60%–100%，低于 50% 时文字可读性显著下降。
- 链接名超长时单行省略 + 悬浮完整提示，避免网格高度抖动。

## 5. 技术架构

### 5.1 技术选型

| 层 | 样本选择 | 自研可选 | 说明 |
|---|---|---|---|
| 语言 | C++（VS2022，x64） | C++17/20 | 单 EXE、启动快、Win32 覆盖完整 |
| 界面 | NIM_Duilib（网易云信 DUI） | NIM_Duilib / 自绘 DUI / Qt | 样本为 XML 驱动的自绘界面 |
| 数据库 | SQLite3（静态链接） | SQLite3 | 零部署、事务、可迁移 |
| 图形 | GDI+ + GDI32 | GDI+ / Direct2D | 图标缩放、Alpha 混合 |
| Shell | Win32 Shell API + OLE | 同左 | 拖拽、托盘、文件图标 |
| 搜索 | 内置 Everything SDK 兼容层 | Everything SDK / 自研索引 | 可选依赖，需降级 |

### 5.5 启动时序

```mermaid
sequenceDiagram
    participant OS as Windows
    participant App as Lucy_x64.exe
    participant DB as SQLite
    participant UI as 主窗口
    participant SH as Shell / Everything

    OS->>App: 启动
    App->>App: CreateMutex("LucyMutex_<hash>")
    alt 已有实例
        App->>UI: 查找 LucyWnd 并唤起
        App-->>OS: 退出
    end
    App->>App: 读取 conf.ini
    App->>DB: 打开 db/link.db 并迁移 schema
    App->>DB: 打开 db/icon.db 读取图标缓存
    App->>App: 加载主题与语言
    App->>UI: 创建 LucyWnd / LucyTopWnd
    App->>SH: 注册热键、托盘、拖放
    App->>App: 按配置决定是否启动即隐藏
    App->>OS: 进入消息循环
```

关键设计点：

- ✅ 单实例通过 `LucyMutex_%08X` 命名互斥量实现；`LucyShareMemory_%08X` 用于实例间共享状态（如唤起命令）。
- ✅ 主窗口类名 `LucyWnd`，热键类名 `LucyTopWnd`，搜索/设置等均为独立窗口类。
- ○ 数据库迁移必须在事务中完成，失败回滚并保留 `.bak`。

### 5.6 线程模型

- 主线程：窗口、消息循环、DUI 渲染、配置与小型 SQLite 操作。
- 工作线程（建议）：图标提取/解码、URL 图标下载禁用（不联网）、大目录扫描、Everything 结果读取。
- 所有 UI 更新通过 `PostMessage` 回主线程；SQLite 连接按线程隔离或加锁。
- 单实例共享内存只保存“唤起/显示”等轻量命令，不共享数据库。

### 5.7 系统集成矩阵

| 集成点 | API | 说明 |
|---|---|---|
| 全局热键 | `RegisterHotKey` / `UnregisterHotKey` | 支持组合键与鼠标侧键 |
| 托盘 | `Shell_NotifyIconW` | 图标 `notify.ico`，可隐藏通知 |
| 拖放 | `DragAcceptFiles` / `DragQueryFileW` / `RegisterDragDrop` | 文件与 OLE 虚拟项 |
| 贴边 | 工作区计算 + `SHAppBarMessage` | 任务栏/多显示器适配 |
| 窗口层级 | `SetWindowPos` / `WorkerW` | 贴桌面或置顶 |
| UWP | `shell:AppsFolder\` + `AppxMetadata` | 通过 AUMID 启动 |
| 虚拟目录 | `SHParseDisplayName` / `SHCreateItemFromIDList` / Pidl BLOB | 我的电脑、控制面板等 |
| 图标 | `SHGetFileInfoW` / `PrivateExtractIconsW` / GDI+ | 文件、EXE/DLL、图片 |
| 开机启动 | 启动目录 `Lucy.lnk` | 可选，不写注册表 |
